# Marca — cópia de uso

Estes arquivos são **cópia**. A fonte única da marca Compendia é:

    ~/claude/marca/compendia/

Estão aqui porque um README de repositório só consegue exibir imagem que esteja
dentro do próprio repositório — caminho para fora não resolve no GitHub.

**Ao mudar a marca, mude lá primeiro e copie para cá.** O contrato (paleta,
tipografia, respiro, o que nunca fazer) está em `brandbook-compendia.md`, na
pasta acima. Não edite estes SVG aqui.
