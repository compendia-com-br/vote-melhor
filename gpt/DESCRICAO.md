# Descrição de vitrine — Vote Melhor

Texto para colar nos campos do GPT Builder em chatgpt.com/gpts/editor. Cada campo abaixo
corresponde a um campo da tela "Configure".

## Nome

```
Vote Melhor
```

## Descrição (campo "Description")

O "melhor" é sobre a sua decisão, não sobre o candidato. Esta descrição não pode dizer o
contrário — ver `AVISO-LEGAL.md` e `plugins/vote-melhor/README.md` na raiz do repositório
para o porquê: a ferramenta não classifica, não pontua, não ordena por mérito e não
recomenda voto, e uma vitrine que prometesse isso venderia propaganda eleitoral, não uma
ferramenta cívica.

```
Ficha de candidatura da eleição de 2026 direto do cadastro oficial do TSE — registro
separado de alegação de campanha, cada dado com fonte e data. O "melhor" é sobre a sua
decisão, não sobre o candidato: não classifica, não pontua, não ordena por mérito e não
recomenda voto. Uma coleção Compendia.
```

(220 caracteres — cabe no limite de 300 do campo "Description" do GPT Builder, com
sobra.)

## Iniciadores de conversa (4)

O GPT Builder aceita até 4. Nenhum pede opinião sobre "quem é melhor" — todos pedem dado
ou verificação, que é o que a ferramenta entrega.

```
Monta a ficha de um candidato pelo nome ou número
```

```
Lista os candidatos a um cargo numa UF
```

```
Essa promessa de campanha cabe no que o cargo pode entregar?
```

```
De onde vem esse dado e quando foi coletado?
```

## O que este texto nunca diz, e por quê

- "Descubra o melhor candidato", "saiba em quem votar", "o ranking dos candidatos",
  "candidato ideal para você" — a ferramenta não faz isso, e prometer é propaganda.
- "Ficha limpa" ou "ficha suja" — não existe como campo consultável (LC 135/2010 exige
  condenação por órgão colegiado); ver `INSTRUCOES.md`, item 3.
- Qualquer verbo de decisão no lugar do usuário ("escolha", "vote em", "recomendamos").
  O verbo certo é sempre o da pessoa: "decida", "compare", "confira".
